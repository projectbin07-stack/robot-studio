# Upstream requests

Changes Robot Studio asked of the projects it reuses, and what happened to
each in milestone 5. Every fix was made in the owning repository with its
own tests, changelog, green CI and a release tag, and Robot Studio's pin was
then moved to that release ([decisions.md](decisions.md), 23).

| Project                   | Before milestone 5   | Now                                                                                                                                                |
| ------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| urdf-inspector            | v0.1.1 (vendored)    | [v0.2.0](https://github.com/projectbin07-stack/urdf-inspector/releases/tag/v0.2.0) (vendored)                                                      |
| lidar-slam-lab            | v0.1.0 (vendored)    | [v0.2.1](https://github.com/projectbin07-stack/lidar-slam-lab/releases/tag/v0.2.1) (vendored; 0.2.0 added the features, 0.2.1 the estimate fix)    |
| rosbag-inspect            | v0.2.0 (Python)      | [v0.3.0](https://github.com/projectbin07-stack/rosbag-inspect/releases/tag/v0.3.0) (`python/pyproject.toml`)                                       |
| encoder-odometry-firmware | v0.1.0 (CI oracle)   | [v0.2.0](https://github.com/projectbin07-stack/encoder-odometry-firmware/releases/tag/v0.2.0) (CI `firmware-interop`)                              |
| imu-calibration-lab       | v0.1.0 (file format) | [v0.2.0](https://github.com/projectbin07-stack/imu-calibration-lab/releases/tag/v0.2.0) (a file its new `combine` command wrote is a test fixture) |

## urdf-inspector

| #   | Request                                                               | Status                                                                                                                                                                                                                                                      |
| --- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `xml.js`: ordered mixed content (text, CDATA, comments kept in order) | **Not done, on purpose.** Only a xacro processor needs it; urdf-inspector checks expanded URDF, where merged text is right. Changing the reader every consumer uses to serve one of them adds risk without a gain there. Robot Studio keeps its own reader. |
| 2   | An `exports` map in `package.json` (audit 35)                         | **Done in 0.2.0.** The public core modules are listed; Robot Studio still vendors by file path at the tag.                                                                                                                                                  |
| 3   | `Finding` with an optional `source` file                              | **Done in 0.2.0.** Elements may carry `source`; each finding gets its top-level element's file. Robot Studio's own mapping of findings to files is gone.                                                                                                    |
| 4   | `checkText` with a location formatter                                 | **Done in 0.2.0** (`{ location }`, default `lineLocation`). Robot Studio's CLI keeps its own report layout (it adds xacro findings and file counts), so it does not use it.                                                                                 |
| 5   | `fk.js`: joint frames in the root frame                               | **Done in 0.2.0** (`jointFrames`); the 3D view's joint axes use it.                                                                                                                                                                                         |
| 6   | A "does this mesh exist" callback for the mesh checks                 | **Done in 0.2.0** (`meshExists` option, `mesh-missing` check). Robot Studio's own finding is gone; it still lists mesh references itself to load them.                                                                                                      |
| -   | Audit 51: a lone file argument                                        | **Done in 0.2.0** (`urdf-inspector robot.urdf` runs `check`).                                                                                                                                                                                               |

## lidar-slam-lab

| #   | Request                                                                                        | Status                                                                                                                                                                                                                                                                                                                                                                                       |
| --- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | A sensor pose for the scan, the grid, scan matching and MCL (audit 27)                         | **Done in 0.2.0** (`scan.origin`, `simulateScan(..., mount)`). Robot Studio's `virtualScan` workaround is gone; scans carry the LiDAR mount.                                                                                                                                                                                                                                                 |
| 2   | A minimum range (audit 27)                                                                     | **Done in 0.2.0** (`LidarConfig.minRange`); Robot Studio's post-filter is gone.                                                                                                                                                                                                                                                                                                              |
| 3   | Obstacle heights in the map format                                                             | **Not done, on purpose.** lidar-slam-lab is a 2D lab whose map format is wall segments; heights matter only for Robot Studio's 3D worlds, which already pass only the obstacles above the LiDAR's plane to the ray caster.                                                                                                                                                                   |
| 4   | An asymmetric fan (`angleMin`)                                                                 | **Done in 0.2.0** (`LidarConfig.angleMin`). Robot Studio keeps turning the mount to the middle of the fan, which gives the same rays; switching would only rename the angles.                                                                                                                                                                                                                |
| 5   | A heading-bias term and an omnidirectional motion model for MCL                                | **Omnidirectional model done in 0.2.0** (`motionModel: "omni"`); Robot Studio uses it on mecanum bases. **Heading-bias term not released:** a per-particle drift state was implemented and measured in the TurtleBot3 corridor runs (seeds 1 to 8, 60 s); depending on its parameters 2 to 5 of the 8 seeds still ended above 1 m RMS. The cause there was random-particle recovery (below). |
| 6   | An `exports` map (audit 35)                                                                    | **Done in 0.2.0.**                                                                                                                                                                                                                                                                                                                                                                           |
| -   | Scan input (audit 20)                                                                          | **Done in 0.2.0:** a scan log reader (LaserScan fields plus odometry per line) and `lidar-slam-lab localize`; `run --scan-log` writes one. Tested only with logs from its own simulator.                                                                                                                                                                                                     |
| -   | Found on the way: the MCL estimate was taken after resampling, so injected particles pulled it | **Fixed in 0.2.1.** On Robot Studio's mecanum square the error stayed at about 0.23 m for every seed; 0.024 to 0.033 m with the fix (recovery on). lidar-slam-lab's own benchmark is unchanged to three decimals.                                                                                                                                                                            |

Effect on Robot Studio (MCL RMS, seeds 1 to 8, development machine; the
full table is in [simulation.md](simulation.md#estimators)): TurtleBot3 in
the corridor loop 0.129 to 7.438 m before, 0.063 to 0.168 m after (with
recovery off, decision 24); the mecanum square 0.231 to 0.237 m before,
0.017 to 0.030 m after; a replay of the differential template 0.200 m
before, 0.021 m after.
